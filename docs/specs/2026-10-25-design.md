# straw-boss-desk design

Approved 2026-10-25.

## Goal

A desktop app for macOS and Windows that lets someone who has never used a terminal (a PM, or a friend of the author) start coding with pi immediately. The main window is the pi-straw-boss GUI. On first launch a wizard builds the whole stack step by step on a bare machine.

## Decisions

| Topic | Decision |
| --- | --- |
| Platforms | macOS and Windows both in v1. Windows is tested in a Windows 11 ARM VM (UTM) on the author's Mac, plus CI runners. |
| Starting point | A bare machine. The app installs Node, Git (Git Bash on Windows), herdr, pi, Claude Code auth, ttt, playwriter, and `gh` and `glab` (only for the code hosts the recipe names) itself. |
| Install location | An app-owned `tools/` folder under the app data directory. No admin rights; the user's own Node, Git, or pi are not touched. pi runs with its own `PI_CODING_AGENT_DIR`. |
| pi packages | Installed from npm at the versions pinned in `stack.json`. No git submodules. When a package lacks a seam the app needs, the change goes upstream and ships as a new npm version. |
| Model access | Each user's own Claude subscription through pi-claude-bridge; the wizard runs the browser OAuth login. Recheck Anthropic's Agent SDK billing policy before wide release. |
| Profile | A generic team profile (AGENTS.md, curated skills, guard rules, roles, models) published as an npm pi package from `profile/` in this repo. Team specifics come from a recipe, one JSON file a team lead hands out. The author's personal weihung-agent-root is not used. See `docs/specs/2026-10-27-team-profile.md`. |
| Models | Sonnet 5.5 by default; Opus 5.5 for reviewer and planner. |
| Git hosting | github.com and self-hosted GitLab; the forges come from the recipe. Login and token storage go through the official CLIs `gh` and `glab`, which keep the token in the OS credential store and serve it to Git through their credential helpers. Device code for github.com, a personal access token with the `api` scope for self-hosted GitLab. Electron `safeStorage` no longer holds the code-host token. |
| Linear | The wizard guides the user to create a Linear API key, stored in the OS keychain; skippable, and the recipe can turn the step off. |
| Language | Traditional Chinese first; the wizard uses i18n so English can follow. The AGENTS.md tells agents to answer in the user's language. |
| Distribution | Public GitHub repo, unsigned builds on GitHub Releases for v1. |
| PM workflow | PMs do not touch git. Agents branch, commit, push, and open the PR or MR by the team profile's PM workflow skill; the PM speaks plainly and answers `ask_user_question` dialogs in the GUI. Worktree rules stay with pi-straw-boss and pi-herdr-agents. |
| Switchboard | A task-oriented main per machine (decided 2026-10-25): it reads the recipe's repository list, clones a repo if needed, opens its base, and opens one main per task with the task as its first message. A general pi-straw-boss feature with a GUI home page for tasks; specified separately, in step with Straw Link. |
| Straw Link | Comes with pi-straw-boss from npm. The app's resident tower is the machine's link holder. Joining by QR needs camera permission (Electron permission handler, macOS `NSCameraUsageDescription`); Windows Chromium has no BarcodeDetector, so PMs there paste the invite text. The relay URL is set per team, from the recipe's `straw.relay`. |
| Updates | Two channels. `stack.json` (tool and package versions, profile version) updates without replacing the app. The shell updates through electron-updater on Windows; on macOS, where Squirrel.Mac refuses unsigned apps, the app offers the new dmg. |

## Architecture

```
straw-boss-desk (Electron, TypeScript)
├─ main/bootstrap   step graph: one Step {detect, install, verify} per tool,
│                   state file and per-step log, resumable and retryable
├─ main/runtime     supervises `herdr server` and a hidden tower pi session,
│                   injects PATH and secrets, waits for straw-boss gui.json,
│                   restarts on crash
├─ main/secrets     Electron safeStorage (Keychain / DPAPI)
├─ main/update      shell update and stack.json update, separately
├─ renderer/wizard  wizard and settings UI
├─ stack.json       tool versions + download URLs + SHA256, pi package
│                   versions, profile version
├─ profile/         the team profile, the npm pi package straw-boss-desk-profile: AGENTS.md, guard rules,
│                   PM workflow skill, models, settings
└─ recipe/          recipe schema, validator, and examples; a recipe is the
                    per-team JSON file (code hosts, repositories, relay, additions)
```

After setup, the app starts `herdr server` (headless) and a tower pi session, reads `gui.json` from the straw-boss state directory, and loads `http://127.0.0.1:<port>/<token>/` in the main window. The URL is the credential; writes are CSRF-protected by the page itself.

### Tools

| Tool | macOS | Windows | Note |
| --- | --- | --- | --- |
| Node | official tarball | official zip | private copy, SHA256 verified |
| Git | standalone git build | PortableGit | pi needs `bash.exe` on Windows |
| herdr | official release binary | `herdr-windows-x86_64.zip` | Windows support is experimental; x64 runs under emulation on Windows ARM |
| pi | npm, private prefix | same | isolated agent dir |
| Claude Code | executable bundled by the Agent SDK | same | only OAuth login needed |
| ttt | npm, private prefix | same | no symlinks |
| playwriter | npm + Chrome extension | same | extension installed by hand, wizard links to it |
| gh | official zip (macOS) | official zip (x64 and arm64) | only if the recipe names github.com; own config folder under app data |
| glab | official tarball (macOS) | official zip (x64 and arm64) | only if the recipe names a GitLab host; own config folder under app data |

### Upstream seams to add

| Package | Gap | Change |
| --- | --- | --- |
| pi-straw-boss | GUI only runs inside a pi session; a shell cannot control it | a supported desk mode: the tower the shell starts opens the GUI, fixed state path, advanced features (remote, stash) can be hidden, folder picking through the native dialog |
| pi-straw-boss | Windows details | `windowsHide` in balance.ts, Windows variant of the `ps` start-time check |
| pi-aaaav | runs `python3` after every write and edit | done: pi-aaaav 1.3.4, then pi-anchorloop's TypeScript validators (pi-anchorloop replaces pi-aaaav) |
| pi-claude-bridge | the author's setup pins a fork commit | confirm the npm release carries those fixes, or publish the fork |
| team-toon-tack | `ttt init` is interactive | non-interactive flags for the wizard |
| pi-anchorloop | `ttsr.ts` applies the repeat policy to blocking tool-call matches: a second matching call in one turn, and the first turn after a resume, are not blocked | a blocking tool-call match skips the repeat policy, or a `repeatMode: always`; `profile/test/rules.test.mjs` holds two `todo` tests that pass once it ships |

### Team profile packages

pi-straw-boss, pi-herdr-agents and its roles, pi-intercom, ask-user, todo, pi-lens, cc-safety-net, memory, pi-anchorloop (replaces pi-aaaav), pi-claude-bridge, pi-robot-hand, pi-herdr-doc-review. Not included: personal writing and life skills, mp-infra, sdlc, thesis-toolkit.

## Phases

| Phase | Work | Anchor |
| --- | --- | --- |
| 0 Spike | On each platform from a clean environment: install herdr, pi, straw-boss; start a headless tower; an Electron window loads the GUI | screenshots from the Windows VM and from macOS |
| 1 Upstream | the seams above, each released to npm | package tests, Windows CI |
| 2 Shell | bootstrap engine, runtime supervisor, wizard, secrets | CI on macOS and Windows runners runs the wizard from zero |
| 3 Profile | AGENTS.md, curated skills, models | the author reads and approves |
| 4 Release | GitHub Actions builds dmg and exe, Releases, updates | an older build upgrades |
| 5 Pilot | one PM goes from nothing to one small merged change | the author and the PM |

If phase 0 shows herdr unusable on Windows, the author decides between delaying Windows and running it under WSL.

### Status

Phase 0 is done on both platforms: `docs/spikes/mac.md` and `docs/spikes/windows.md`. herdr works natively on Windows; WSL is not needed.

Shipped from phase 1 so far: pi-aaaav 1.3.4 (no Python), pi-straw-boss 0.43.0 (roles survive a herdr restart, tower close button, deploy progress panel, new folder, column folder picker).

Work order the author left to this project (2026-10-26):

1. Small upstream fixes found on Windows: Windows hidden and system folders out of the picker; a restored tower takes over closing the mains it opened.
2. Desk mode in pi-straw-boss (spec first, the author approves): the tower the shell starts opens the GUI without a browser and without typed commands, a state path the shell sets, the herdr pi integration checked at start. This makes the shell's start reliable, so it comes before phase 2.
3. Phase 3 profile, started early because it needs no upstream change: team AGENTS.md and the PM workflow skill, including the two agent rules from the Windows spike.
4. Phase 2 shell on desk mode, with the checks phase 0 skipped (SmartScreen, updater, DPAPI, account checks).
5. Switchboard spec, after Straw Link step 3 settles the GUI home page and the tower's role.
